# Code Refactoring Skill

A comprehensive guide for intelligent code refactoring, import fixing, code beautification, and cleanup operations.

## Overview

This skill provides patterns and workflows for:
- Systematic code restructuring with validation
- Import path fixing after refactoring
- Code readability improvements
- Comment cleanup and optimization
- Code formatting standardization

## Core Principles

1. **Preserve Functionality**: Never break working code
2. **Incremental Changes**: Apply refactorings step by step
3. **Validation After Each Change**: Test immediately after modifications
4. **Git Safety**: Always create checkpoints before changes
5. **Session Continuity**: Maintain state across sessions

- Large-scale code restructuring

- Pattern consistency enforcement

## Key Features

### Session Intelligence
Maintain refactoring progress across sessions with state tracking.

### Extended Thinking
Complex refactoring scenarios trigger deep analysis for:
- Multi-step transformation paths
- Risk mitigation strategies
- Dependency graph analysis
- Performance implications

### Validation & Refinement
Built-in validation ensures:
- No behavioral changes

- Git checkpoints before changes
- Incremental commits at logical points
- Test validation after each step
- Clear rollback strategy
- No AI attribution in commits
