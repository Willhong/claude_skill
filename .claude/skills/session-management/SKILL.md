# Session Management Skill

Development session tracking with CLAUDE.md integration and context preservation.

## Overview

This skill provides patterns for:
- Starting documented development sessions
- Summarizing and preserving session context
- CLAUDE.md integration for project memory

## Core Principles

1. **Context Preservation**: Maintain session continuity
2. **Documentation**: Record important decisions
3. **Progress Tracking**: Monitor session accomplishments
4. **Knowledge Transfer**: Preserve insights
5. **Clean Sessions**: Structured start and end

## Resource Files

- **SESSION_START.md** - Begin documented sessions with CLAUDE.md integration
- **SESSION_END.md** - Summarize and preserve session context

## When to Use This Skill

- Starting new development sessions
- Ending productive sessions
- Preserving important context
- Knowledge documentation
- Team handoffs

## Key Features

### Session Start
- Initialize session tracking
- Load project context
- Review CLAUDE.md
- Set session goals
- Prepare workspace

### Session End
- Summarize accomplishments
- Document decisions made
- Update CLAUDE.md
- Preserve important context
- Plan next steps

### CLAUDE.md Integration
- Project memory file
- Persistent context
- Decision history
- Important patterns
- Lessons learned

## Safety Guarantees

- Preserve all work
- No context loss
- Clear documentation
- Proper handoff information
- Maintain project history
