# Security Analysis Skill

Comprehensive security vulnerability detection, analysis, and remediation workflows.

## Overview

This skill provides patterns for:
- Security vulnerability scanning and detection
- Proactive issue prediction
- Remediation tracking across sessions
- Risk categorization and prioritization

## Core Principles

1. **Defense in Depth**: Multiple layers of security
2. **Least Privilege**: Minimal necessary permissions
3. **Secure by Default**: Safe configurations out of the box
4. **Track Everything**: Complete audit trail
5. **Fix Critical First**: Priority-based remediation

## Resource Files

- **SECURITY_SCAN.md** - Comprehensive vulnerability analysis with remediation tracking
- **PREDICT_ISSUES.md** - Proactive problem detection with timeline estimates

## When to Use This Skill

- Security audits and assessments
- Vulnerability remediation
- Credential exposure detection
- Dependency security analysis
- Configuration hardening

## Key Features

### Extended Thinking for Security
Complex security scenarios trigger deep analysis:
- Attack vectors identification
- Chain vulnerability detection
- Business logic flaws
- Timing attacks and race conditions
- Supply chain vulnerabilities

### Risk Categorization
- **Critical**: Immediate exploitation possible
- **High**: Serious vulnerabilities
- **Medium**: Should be addressed
- **Low**: Best practice improvements

### Session Continuity
Track remediation progress across sessions:
- Vulnerability list and status
- Fixed vs pending items
- Risk summary dashboards

## Safety Guarantees

- Never expose secrets in commits
- Preserve existing security measures
- No regression in security posture
- Complete audit trail
- Safe credential handling
