# Code Quality Skill

Multi-dimensional code analysis, testing, and quality assurance workflows.

## Overview

This skill provides patterns for:
- Comprehensive code review with multiple perspectives
- Intelligent test execution and failure analysis
- Quality metrics and improvements

## Core Principles

1. **Multi-Agent Analysis**: Security, performance, quality, architecture
2. **Intelligent Testing**: Smart failure analysis and fixes
3. **Objective Assessment**: Data-driven quality metrics
4. **Continuous Improvement**: Track quality over time
5. **Best Practices**: Follow industry standards

## Resource Files

- **REVIEW.md** - Multi-agent analysis (security, performance, quality, architecture)
- **TEST.md** - Run tests with intelligent failure analysis

## When to Use This Skill

- Code review sessions
- Test execution and debugging
- Quality gate validation
- Performance analysis
- Architecture assessment

## Key Features

### Multi-Agent Code Review
Specialized analysis from multiple perspectives:
- Security analysis agent
- Performance optimization agent
- Architecture review agent
- Code quality agent

### Intelligent Test Analysis
- Run tests with context awareness
- Analyze failures intelligently
- Suggest fixes based on patterns
- Track test coverage

### Quality Metrics
- Complexity analysis
- Maintainability scores
- Performance benchmarks
- Security posture assessment

## Safety Guarantees

- Objective analysis without bias
- No breaking changes from reviews
- Preserve functionality during improvements
- Clear actionable recommendations
- Evidence-based suggestions
