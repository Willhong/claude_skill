# Git Workflow Skill

Professional git operations including smart commits, project cleanup, and safe rollback strategies.

## Overview

This skill provides patterns for:
- Intelligent commit message generation
- Debug artifact cleanup
- Safe undo/rollback operations
- Git safety protocols

## Core Principles

1. **Meaningful Commits**: Clear, conventional commit messages
2. **Clean History**: No debug artifacts or temporary files
3. **Safe Operations**: Always with backups and checkpoints
4. **No AI Attribution**: Clean commit ownership
5. **Preserve Work**: Never lose important changes

## Resource Files

- **COMMIT.md** - Smart conventional commits with pre-commit checks
- **CLEANPROJECT.md** - Remove debug artifacts with git safety
- **UNDO.md** - Safe rollback with git checkpoint restore

## When to Use This Skill

- Creating meaningful commits
- Cleaning up development artifacts
- Rolling back changes safely
- Maintaining clean git history
- Pre-commit quality validation

## Key Features

### Smart Commit Analysis
- Analyze changes to determine type (feat/fix/refactor/etc.)
- Identify scope/component affected
- Generate conventional commit messages
- Pre-commit quality checks (build, test, lint)

### Project Cleanup
- Remove debug artifacts safely
- Preserve important files
- Git-aware cleanup (respects .gitignore)
- Backup before deletion

### Safe Undo Operations
- Git checkpoint-based rollback
- Selective change reversal
- Clear recovery paths

## Safety Guarantees

- NEVER add AI attribution or signatures
- NEVER modify git config or credentials
- Always verify before destructive operations
- Create backups before cleanup
- No emojis in commits or PRs
