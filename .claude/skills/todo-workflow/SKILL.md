# TODO Workflow Skill

Complete TODO lifecycle management from discovery to resolution and issue tracking.

## Overview

This skill provides patterns for:
- Finding and organizing TODO comments
- Creating contextual TODO markers
- Intelligent TODO fixing with context
- Converting TODOs to GitHub issues

## Core Principles

1. **Complete Lifecycle**: From creation to resolution
2. **Context Awareness**: Understand why TODOs exist
3. **Intelligent Fixing**: Smart implementation based on context
4. **Issue Integration**: Connect to project management
5. **Track Progress**: Monitor TODO resolution

## Resource Files

- **FIND_TODOS.md** - Locate and organize development tasks
- **CREATE_TODOS.md** - Add contextual TODO comments based on analysis
- **FIX_TODOS.md** - Intelligently implement TODO fixes with context
- **TODOS_TO_ISSUES.md** - Convert code TODOs to GitHub issues

## When to Use This Skill

- Technical debt assessment
- Task discovery and organization
- Systematic TODO resolution
- Issue tracking integration
- Development task management

## Key Features

### TODO Discovery
- Find all TODO/FIXME/HACK comments
- Categorize by type and priority
- Map locations and context
- Generate actionable reports

### Contextual TODO Creation
- Add meaningful TODO comments
- Include necessary context
- Link to related code
- Set appropriate priorities

### Intelligent TODO Fixing
- Understand TODO context
- Implement fixes appropriately
- Validate changes
- Remove resolved TODOs

### GitHub Integration
- Convert TODOs to issues
- Preserve context and references
- Link issues to code locations
- Track resolution status

## Safety Guarantees

- Preserve code functionality
- Don't remove important TODOs prematurely
- Maintain code documentation
- Clear issue tracking
- No duplicate issue creation
