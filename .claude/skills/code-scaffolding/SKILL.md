# Code Scaffolding Skill

Generate complete features, implement code from external sources, and analyze contribution readiness.

## Overview

This skill provides patterns for:
- Feature scaffolding from existing patterns
- Code implementation from URLs or specifications
- Contribution analysis and readiness checks

## Core Principles

1. **Pattern Consistency**: Follow existing project patterns
2. **Complete Features**: Generate all necessary components
3. **Validation Phase**: Verify integration completeness
4. **Contribution Ready**: Understand project standards
5. **Adapt Not Copy**: Customize for your context

## Resource Files

- **SCAFFOLD.md** - Generate complete features from project patterns
- **IMPLEMENT.md** - Import and adapt code from any source with validation
- **CONTRIBUTING.md** - Complete contribution readiness analysis

## When to Use This Skill

- Creating new features
- Implementing external code
- Preparing for contributions
- Understanding project patterns
- Generating boilerplate

## Key Features

### Feature Scaffolding
- Analyze existing patterns in project
- Generate consistent new features
- Include all necessary files (components, tests, types)
- Follow project conventions

### Code Implementation
- Import from URLs, files, or specifications
- Adapt to project context
- Validation phase for completeness
- Integration verification

### Contribution Analysis
- Understand coding standards
- Check commit message formats
- Verify testing requirements
- Analyze PR conventions

## Safety Guarantees

- Respect existing patterns
- No breaking changes
- Complete feature generation
- Proper integration testing
- Follow project conventions
